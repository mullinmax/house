# Ladder laser cut kit, no strip tread option (SendCutSend)

Written by `LADDER_TREAD_STRIPS=0 python3 tools/ladder_drawings/export_mono_kit.py tools/ladder_drawings/sendcutsend_no_strip`.
Same conventions as ../sendcutsend/README.md. Differences from the default (strip) kit:
- No tread strips. Treads are 1 3/4 in white oak and the riser lips are taller (3.65 in) so the gap under each tread stays 3 7/8 in (4 in sphere rule).
- Tread brackets have no front flange; the seat tab runs the whole top edge and is 2 1/2 in wide, with 3 x 11/32 holes for 5/16 x 1 1/2 lags up into the tread.
- The landing and balcony decks stay 1 7/16 in oak.
