# Ladder laser cut kit (SendCutSend)

Flat DXFs written by `tools/ladder_drawings/export_mono_kit.py`, in inches.
Cut lines on layer 0, bend lines dashed on layer BEND.
Quantity is in each file name. Material: A36 hot rolled pickled and oiled steel, no finish (it gets cold blued),
1/4 in except the base plates and balcony L plates (3/8 in).
Round 6 (11/24/2026): tread bracket corners rounded; one head clip pair per stringer top, the same part on both flights
(qty 2 of each hand); the post saddle now has cheeks up the stringer and tabs to the landing beam, replacing the foot clips
and the lower head angles. Base plate clip holes are countersunk from the bottom for flat head screws; nothing is tapped.
